# Duplicate Question Pair Detection

An NLP and Machine Learning project to identify whether two given questions are semantically similar or not.

### Project Description

This project predicts whether a pair of questions have the same meaning, even when they are written differently.

### Tech Stack

- Python
- NumPy
- Pandas
- Scikit-learn
- XGBoost
- NLTK
- Streamlit

### Dataset

[Quora Question Pairs Dataset – Kaggle](https://www.kaggle.com/c/quora-question-pairs)
